# 📚 Portfólio de Aprendizados

Repositório criado para registrar e organizar os conteúdos, exemplos, exercícios e anotações desenvolvidos ao longo da disciplina.

O objetivo é utilizar este espaço como um portfólio de aprendizagem, permitindo acompanhar a evolução dos conhecimentos adquiridos durante as aulas.

## 📖 Conteúdos

| Aula    | Conteúdo                         | Status          |
| ------- | -------------------------------- | --------------- |
| Aula 01 | Conteúdos iniciais da disciplina | ✅ Concluído     |
| Aula 02 | Conteúdos apresentados em sala   | ✅ Concluído     |
| Aula 03 | Próximo conteúdo                 | 🔄 Em andamento |

## 📂 Organização

Cada aula possui uma pasta própria contendo:

* **Exemplos:** códigos desenvolvidos durante as aulas;
* **Exercícios:** atividades práticas propostas;
* **Anotações:** principais conceitos e aprendizados;
* **README:** resumo do conteúdo trabalhado na aula.

## 🎯 Objetivo

Este repositório será atualizado continuamente durante a disciplina, registrando novos conteúdos, atividades e exercícios desenvolvidos em cada aula.

Além de servir como material de estudo, o repositório também funcionará como um portfólio para demonstrar a evolução prática e teórica ao longo da disciplina.
